## 질문
"ai가 출시된 이후로 개발자들의 개발의 질이 정말로 올라갔을까?"
## 왜 이 주제인가 (팀이 씁니다)
두 명 모두 ai를 즐겨 씁니다. ai로 바이브코딩하는 것을 좋아하는 둘이 뭉쳐, 과연 실제 개발자들도 바이브코딩을 즐겨 쓸 지에 대해 탐구하게 되었습니다.
- 20119 이나율: 평소 AI를 활용해 코딩하는 것을 좋아하고, AI가 코딩을 도와주면 개발 속도나 결과물의 질이 실제로 좋아지는지 궁금했습니다. 그래서 실제 개발자들의 GitHub 커밋 데이터를 통해 AI 활용 여부와 개발 작업의 종류 사이에 어떤 관계가 있는지 알아보고 싶었습니다.
- 20508 김한별: - 저도 AI가 등장한 이후 텍스트 코딩을 시작했기 때문에, 실제로 AI의 도입이 개발자들의 개발량 증가로 이어졌을까 궁금해졌습니다. GitHub 커밋 데이터를 활용해 AI가 작성한 커밋과 인간이 작성한 커밋, AI의 도움을 받은 커밋 등을 비교하고, AI 활용이 실제 개발 활동에 어떤 영향을 미치는지 알아보고자 했습니다.
